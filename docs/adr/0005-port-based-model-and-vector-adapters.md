# ADR-0005：模型与向量存储通过端口适配

- 状态：Accepted
- 日期：2026-08-20

## 背景

模型供应商、协议、价格和向量存储可能变化，普通测试也不能依赖网络和付费服务。

## 决策

领域层只依赖 `ModelGateway`、`EmbeddingGateway` 和 `VectorStorePort`。生产候选实现使用
可配置模型适配器和 Qdrant；普通测试使用确定性 Stub、固定 Embedding 和内存向量存储。
依赖版本在工程初始化时根据官方兼容矩阵固定并通过构建验证。

## 后果

模型选型和存储替换不会改变业务编排，测试可离线重复；代价是需要维护清晰的领域 DTO
和适配器契约，不能让供应商 SDK 类型泄漏进业务层。
