# ADR-0012：P4-3 单次调用与费用预留边界

- 状态：Accepted；冻结时为实施输入，当前实现与验收状态见[P4-3记录](../acceptance/2026-11-02-p4-3-governance.md)
- 日期：2026-11-02

已有单次调用占用解决重复付费请求，现阶段不能为了自动备用或费用结算重投而删除它。P4-3 先建立单主模型的可追溯成本治理。

采用[调用与费用契约 v1](../contracts/phase4-3-call-budget-v1.md)：本地版本与内容哈希绑定、精确人民币费用预留、MySQL预算与调用占用原子取得、Redis短期配额与持有者租约、未知费用保留及有界恢复。主模型未发请求前可路由；结果不确定时不切换供应商。无合格真实备用模型时拒绝调用。

本决策细化 ADR-0010，不把多供应商自动降级视为现有能力。代价是对未知结果采取保守占用和人工/供应商账单核对；收益是不会因消息重投、Redis故障或账本写入异常绕过预算与既有一次调用语义。
