# ADR-0001：Copilot 使用独立项目和仓库

- 状态：Accepted
- 日期：2026-08-20

## 背景

FinGuard Core 已经是可独立构建、测试和演示的确定性业务系统。AI 依赖、模型配置、RAG
数据管道和实验节奏与 Core 明显不同。

## 决策

FinGuard Copilot 使用独立仓库、数据库、构建和部署单元。两个项目首阶段通过 HTTP API
连接，Core 不依赖 Spring AI、模型供应商或向量存储。

## 后果

Core 的稳定性不会被 AI 实验影响，两个项目可以独立展示和演进；代价是必须维护跨服务
认证、契约测试、超时和部署连接配置。
