# ADR-0006：异步处理前同步捕获脱敏事实

- 状态：Accepted
- 日期：2026-08-20

## 背景

模型调用延迟适合异步处理，但后台任务若继续访问 Core，就必须保存或替换用户 JWT。
保存 JWT 会扩大泄漏面，纯哈希又不能复现当时的业务输入。

## 决策

创建分析时同步调用 Core 验证 `REVIEWER` 并捕获最少、脱敏、版本化的事实快照；在同一
MySQL 事务中保存运行、快照和 Outbox 事件，成功后返回 `202` 并立即丢弃 JWT。后台任务
只使用不可变快照。快照默认保留 30 天并保存校验和。

## 后果

无需保存用户凭证，运行能够在保留期内复现；代价是创建请求受 Core 延迟影响，Copilot
必须承担受控的短期事实快照存储和删除责任。
