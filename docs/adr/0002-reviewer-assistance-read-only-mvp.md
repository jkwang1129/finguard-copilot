# ADR-0002：首版是面向 REVIEWER 的只读审核辅助

- 状态：Accepted
- 日期：2026-08-20

## 背景

自主审批会把概率性模型输出直接变成业务副作用，并绕开 Core 已有的职责分离、乐观锁和
审计价值。通用聊天又无法形成清晰业务闭环。

## 决策

MVP 只服务 `REVIEWER`，围绕一个 `reviewTaskId` 生成解释、证据、引用、建议和限制。
Copilot 不注册写工具，最终决定由审核人员在 Core 中独立完成。

## 后果

系统边界清楚，安全测试和演示可控；代价是首版不会展示自动处置。后续写工具必须单独
设计人工批准凭证、任务版本复查、Core RBAC 和审计，不能从本 ADR 推导出授权。
