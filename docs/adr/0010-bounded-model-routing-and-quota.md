# ADR-0010：多模型路由受预算、配额和安全策略约束

- 状态：Accepted
- 日期：2026-08-20

## 背景

单模型无法证明选型能力，也容易受供应商超时和限流影响；无条件自动切换又可能突破成本、
上下文或数据边界。

## 决策

完整项目默认接入 Qwen/DashScope 和 DeepSeek 的 OpenAI-compatible 候选适配器。
`ModelRouter` 根据任务类型、质量等级、上下文长度、剩余预算和供应商健康状态选择模型。
Redis 保存短期用户配额、供应商并发租约和健康状态；MySQL 用量账本保存最终 Token、成本
和价格表版本。降级只能选择相同数据分类、地域和安全等级的供应商，不得绕过安全策略或
超过单次预算。

## 后果

模型选择、成本和供应商故障可以量化演示。代价是需要维护价格表、路由测试、Redis 降级
策略和多供应商契约；不会缓存动态业务事实或审核结论。
