## 未关闭条件和后续归属

- 原计划写有“安全负例均 fail-closed”，但没有事先冻结穷举的攻击集；当前样例通过不能证明泛化注入安全。P4-2 需建立独立评测数据与报告，明确验收样本、漏报和误报；本项保持未勾选，避免改变原验收条件后直接宣布完成。
- 自由审核文本不是当前公共能力；若未来引入，须先补输入限制、快照/幂等/隐私及端到端注入测试，不能将现有组件测试当成 API 验收。
- 模型工具执行未开放；Phase 5 引入时再实现工具白名单、参数与 URL 校验、权限及副作用隔离，并重新验证安全边界。
- 生产部署、真实业务政策和规模化质量证据属于 P4-6 及实际部署验收；本工作区不声称已有生产验收。
